# MrNoe

A multipurpose Discord bot built with JavaScript and Discord.js, developed to provide diverse features for Discord communities.

MrNoe reached **100,000+ users** and included features organised into categories such as Animals, Fun, Information, NSFW, and Other.

## Tech Stack

- JavaScript
- Discord.js

## Features

- **Animals** — Animal-related commands
- **Fun** — Entertainment and community engagement
- **Information** — Informational commands
- **NSFW** — Age-restricted commands
- **Other** — Additional bot functionality
